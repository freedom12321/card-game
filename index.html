R Code (simulation)

card <- c("A","K","Q","J","10",
         "9","8","7","6","5",
         "4","3","2")

plays <- 5000000
win   <- vector()

for (i in 1:plays) {
  draw <- sample(card, 1)
  win[i] <- ifelse(draw=="A", 15,
             ifelse(draw=="K", 15,
             ifelse(draw=="Q", 15,
             ifelse(draw=="J", 15,
             ifelse(draw=="10",10,
             ifelse(draw=="9",  9,
             ifelse(draw=="8",  8,
             ifelse(draw=="7",  7,
             ifelse(draw=="6",  6,
             ifelse(draw=="5",  5,
             ifelse(draw=="4",  4,
             ifelse(draw=="3",  3,
                    2))))))))))))
}

avg.pmt <- sum(win) / length(win)
sum(win)
avg.pmt

Each draw is independent. As n grows, the running average converges to the theoretical expectation — that is the Law of Large Numbers in action.
